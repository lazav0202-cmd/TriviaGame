# TriviaGame

A programming trivia game written in **C++20** with [raylib](https://www.raylib.com). Questions are generated on the fly by AI (Claude), and a run lasts as long as you keep answering correctly: one wrong answer ends the game. This is a learning project, so the code is heavily commented.

**Current version: 2.0.0** · [Changelog](CHANGELOG.md)

> **Note:** the in-game text (menus, questions) and the comments in the source code are in Russian.

## Features

- Main menu: play, shop, settings, about, exit
- Questions are generated by AI during the game; difficulty grows with your streak of correct answers
- Streak mode: the game continues while you answer correctly, the first mistake ends the run, and your best streak is saved
- Fullscreen by default; switch between fullscreen and windowed mode in the settings or with F11
- Animations: transitions between questions, button entrance / hover / press effects, confetti and screen shake
- Coins for every 5 correct answers; the shop sells button designs and music tracks
- All music and sound effects are synthesized in code, no audio files needed
- Playable without AI using a built-in set of fallback questions ("Play without AI")

## Requirements

A g++ compiler with C++20 support, plus the **raylib** and **libcurl** libraries.

**Windows (MSYS2).** Install [MSYS2](https://www.msys2.org), open the **MSYS2 UCRT64** shell and run:

```
pacman -S mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-raylib mingw-w64-ucrt-x86_64-curl mingw-w64-ucrt-x86_64-pkgconf
```

**Linux (Ubuntu/Debian):**

```
sudo apt install g++ pkg-config libraylib-dev libcurl4-openssl-dev
```

**macOS:**

```
brew install raylib curl pkg-config
```

## Build and run

```
cd src
g++ -std=c++20 main.cpp ai.cpp -o trivia -pthread $(pkg-config --cflags --libs raylib libcurl)
./trivia
```

On Windows, run it from the same MSYS2 shell. To make `trivia.exe` start with a double click, copy the DLLs it needs next to it:

```
ldd trivia.exe | grep /ucrt64/ | awk '{print $3}' | xargs -I{} cp {} .
```

If you see squares instead of Cyrillic letters, put any `.ttf` font with Cyrillic support next to the game and name it `font.ttf`.

## API key for the AI

Questions are generated by Claude through the [Claude API](https://docs.claude.com), so you need an API key. It is a separate paid service and is not included in a Claude subscription.

1. Create a key in the Claude Console (API keys section) and make sure your account has credit (new accounts may get a small trial credit).
2. In the game: **Settings → API key → Paste → Save**. Alternatively, create a file named `api_key.txt` next to the game with the key on the first line, or set the `ANTHROPIC_API_KEY` environment variable.

> **Never publish your key.** `api_key.txt` is listed in `.gitignore`, so keep it there. If a key ever leaks, delete it in the Console right away and create a new one.

The model is set by the `AI_MODEL` constant in `src/ai.hpp`.

## Controls

| Action | Keys |
| --- | --- |
| Choose an answer | mouse or `1`-`4` |
| Skip the pause after an answer | `Space` or `Enter` |
| Back / to the menu | `Esc` |
| Fullscreen / windowed | `F11` |

## Project structure

| File | Purpose |
| --- | --- |
| `src/main.cpp` | game screens and the main loop |
| `src/ai.hpp`, `src/ai.cpp` | Claude API request via libcurl and response parsing |
| `src/json.hpp` | a tiny JSON parser |
| `src/ui.hpp` | buttons, animations, font, particles |
| `src/audio.hpp` | sound and music synthesis |
| `src/save.hpp` | progress saving to `save.txt` |
| `src/questions.hpp` | fallback questions for the mode without AI |

`ai.cpp` is a separate file on purpose: on Windows libcurl pulls in `windows.h`, whose names clash with raylib, so the two headers must never be included in the same `.cpp` file.
