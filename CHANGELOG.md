# Changelog

This project follows [semantic versioning](https://semver.org). A major update of the game increases the first number.

## [2.0.0]

### Added
- Questions are generated by AI (Claude API) in a background thread, so the game never freezes; questions are prefetched ahead of time
- Question difficulty grows with the streak; repeated questions are filtered out
- API key screen; the key is stored in `api_key.txt`
- Streak mode: the first mistake ends the run; the best streak is saved
- Error screen with "Retry", "Change API key" and "Play without AI" buttons
- Fullscreen by default, with a switch in the settings and the F11 key; the picture scales to any monitor
- Animations: questions flying in and out, cascading button entrance, hover, press, a ring after a click, pulsing correct answer and shaking wrong answer, an animated game-over screen
- New sounds: hover, question transition, game over
- The game version is shown on the "About" screen

### Changed
- Game resolution is now 1280x720 instead of 900x680; all screens were re-laid out
- The built-in questions are used only in the "Play without AI" mode

### Fixed
- Clicking an answer to move on no longer answers the next question blindly: the transition is automatic and clicks are ignored during animations

## [1.0.0]

### Added
- Main menu: play, shop, settings, about, exit
- 22 built-in programming questions
- Coins for every 5 correct answers; shop with button designs and music
- Music and sound effects synthesized in code; effects for right and wrong answers
- Progress saved to `save.txt`
